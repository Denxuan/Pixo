# 剪贴板工具设计

> 状态：草案　｜　适用版本：Pixo 0.1.x 之后的第一版剪贴板功能

## 1. 目标与范围

在 Pixo 工具箱中新增“剪贴板”工具，记录用户复制过的内容，方便查找和再次使用。

第一版包含：

- 监听系统剪贴板变化并生成历史记录。
- 支持文本、图片、文件路径三类内容。
- 历史持久化到本机，重启后保留。
- 搜索、按类型筛选、置顶（收藏）、删除、清空。
- 全局快捷键唤出快速面板，选中条目后写回剪贴板。
- 隐私控制：暂停监听、识别密码管理器等标记的敏感内容、按来源应用排除。

不包含：

- 云同步、跨设备共享、任何上传。
- 自动模拟粘贴到目标应用（需要辅助功能权限，Wayland 下不可行，留待后续评估）。
- 富文本（HTML/RTF）的完整保留；第一版只记录其纯文本形式。
- PRIMARY 选区（Linux 鼠标选中即复制）的记录。

## 2. 设计原则

- **默认关闭，用户主动启用。** 剪贴板可能含有密码、令牌等敏感数据，首次启用时说明会记录什么、存在哪里。
- **只在本机。** 数据存放在应用数据目录，不经过网络；不新增网络权限。
- **系统能力在 Rust，界面在前端。** 监听、读写剪贴板、存储、全局快捷键在 Rust 实现；搜索输入、列表展示、筛选交互在前端。
- **不静默失败。** 平台不支持、权限缺失、内容过大被跳过等情况，都通过状态接口告诉前端，由界面明确提示。
- **避免数据丢失。** 置顶条目不参与自动清理；清空需要确认；写入使用事务。

## 3. 平台支持

| 能力 | macOS | Windows | Linux X11 | Linux Wayland |
|---|---|---|---|---|
| 变化监听 | 轮询 `NSPasteboard.changeCount` | `AddClipboardFormatListener` | XFixes 选区事件 | `ext-data-control-v1` / `wlr-data-control` |
| 文本 / 图片 / 文件 | 支持 | 支持 | 支持 | 依赖合成器 |
| 来源应用 | 近似（变化时的前台应用） | `GetClipboardOwner` 所属进程 | 所有者窗口的 `_NET_WM_PID` | 不可用 |
| 全局快捷键 | 支持 | 支持 | 支持 | 不支持，提供替代方案 |

### 3.1 macOS

- macOS 没有剪贴板变化通知，使用 500 ms 间隔读取 `changeCount`，只有计数变化时才读取内容。读取 `changeCount` 本身开销很小。
- 较新的 macOS 版本会在应用以编程方式读取剪贴板时向用户弹出隐私提示。需要在目标系统版本上验证提示的触发条件，并在界面中说明，必要时引导用户在系统设置中授权。**这项在实现前必须实测。**
- 敏感标记：`org.nspasteboard.ConcealedType`、`org.nspasteboard.TransientType`、`org.nspasteboard.AutoGeneratedType`。

### 3.2 Windows

- 在独立线程创建消息窗口，注册 `AddClipboardFormatListener`，处理 `WM_CLIPBOARDUPDATE`。
- `OpenClipboard` 可能因其他程序占用而失败，按退避重试（例如 3 次，间隔 50/100/200 ms），仍失败则记录为一次读取失败并更新状态。
- 格式：`CF_UNICODETEXT`、`PNG` / `CF_DIBV5`、`CF_HDROP`。
- 敏感标记：存在 `ExcludeClipboardContentFromMonitorProcessing`，或 `CanIncludeInClipboardHistory` 为 0 时跳过。

### 3.3 Linux X11

- 通过 XFixes 订阅 `CLIPBOARD` 选区所有者变化，变化后立即读取，因为复制来源进程退出后内容会消失。
- 文件格式：`text/uri-list`、`x-special/gnome-copied-files`。
- 敏感标记：`x-kde-passwordManagerHint` 值为 `secret`。

### 3.4 Linux Wayland

- Wayland 只允许获得焦点的客户端读取剪贴板，后台监听依赖 data-control 协议。wlroots 系合成器（Sway、Hyprland 等）和 KDE Plasma 支持；GNOME（Mutter）目前不支持，需要在实现时复核最新情况。
- 启动时检测协议是否可用。不可用时监听状态为“不支持”，界面明确说明原因，不退回到不可靠的 XWayland 方案假装可用。此时仍可在 Pixo 获得焦点时手动“读取当前剪贴板”。
- 全局快捷键：Tauri 全局快捷键插件在 Wayland 下不可用。提供命令行参数 `pixo --clipboard-panel`，配合单实例插件转发给已运行的实例，用户可在桌面环境的系统快捷键设置里绑定这条命令。后续可评估 xdg-desktop-portal 的 GlobalShortcuts 接口。

## 4. 用户界面

### 4.1 主界面（工具页）

工具箱侧栏新增“剪贴板”入口。引入 `HashRouter`，现有 JSON 格式化和剪贴板各自成为一个路由页面。

页面结构：

- 顶部：监听状态（运行中 / 已暂停 / 不支持 / 权限不足）、暂停开关、设置入口。
- 工具栏：搜索框、类型筛选（全部 / 文本 / 图片 / 文件 / 置顶）、清空按钮。
- 列表：置顶条目在前，其余按最近复制时间倒序。每条显示类型图标、内容预览（文本前 200 字、图片缩略图、文件名列表）、时间、来源应用，以及复制、置顶、删除操作。
- 空状态：区分“尚未启用”“暂无记录”“没有匹配结果”。

### 4.2 快速面板

- 独立的无边框小窗口（标签 `clipboard-panel`），按需创建，失去焦点后隐藏。
- 打开时搜索框自动聚焦；上下键选择，回车写回剪贴板并隐藏面板，`Esc` 关闭，`Ctrl/Cmd + P` 切换置顶。
- 第一版只写回剪贴板，不自动粘贴；面板底部提示“已复制，可直接粘贴”。

### 4.3 设置

| 设置 | 默认值 | 说明 |
|---|---|---|
| 启用剪贴板记录 | 关闭 | 首次开启时展示说明 |
| 记录类型 | 文本、图片、文件 | 可分别关闭 |
| 最大条数 | 500 | 置顶不计入 |
| 保留天数 | 30 | 置顶不过期；0 表示不按时间清理 |
| 单条文本上限 | 1 MB | 超出则跳过并计数 |
| 单张图片上限 | 20 MB（解码后） | 超出则跳过并计数 |
| 全局快捷键 | macOS `Cmd+Shift+V`，其他 `Ctrl+Shift+V` | 冲突时提示用户修改 |
| 排除的应用 | 空 | 按应用标识匹配 |
| 跳过敏感标记内容 | 开启 | 见第 7 节 |

### 4.4 无障碍与国际化

- 所有操作可用键盘完成；列表使用 `listbox` 语义，图标按钮提供 `aria-label`。
- 文案全部走 i18n，例如 `zdx.label.clipboard.title`、`zdx.text.clipboard.empty`、`zdx.placeholder.clipboard.search`、`zdx.text.clipboard.status.unsupported`；中英文同步维护。
- 时间显示使用 `Intl.RelativeTimeFormat` 并跟随当前语言；条数使用 i18next 复数规则。
- 用户复制的内容本身不翻译。

## 5. 架构

```
系统剪贴板
   │ 变化事件（各平台 monitor）
   ▼
ClipboardService（Rust）
   ├─ 读取内容 → 隐私过滤 → 大小检查 → 计算哈希去重
   ├─ ClipboardStore：SQLite + 图片文件
   └─ 发出事件 clipboard://changed、clipboard://status
   ▲
   │ Tauri 命令
前端 src/api/clipboard.ts → 页面 / 快速面板
```

│   ├── error.rs           错误类型与稳定错误码
│   └── monitor/

## 6. 数据与存储

### 6.1 位置

- 数据库：`<app_data_dir>/clipboard/history.db`，开启 WAL。
- 图片：`<app_data_dir>/clipboard/images/<sha256>.png`，缩略图 `<sha256>.thumb.png`（长边 256 px）。

### 6.2 表结构

```sql
CREATE TABLE clip_items (
  id              INTEGER PRIMARY KEY,
  kind            TEXT    NOT NULL CHECK (kind IN ('text', 'image', 'files')),
  content_hash    TEXT    NOT NULL UNIQUE,
  text            TEXT,            -- kind = text 时的内容
  files_json      TEXT,            -- kind = files 时的路径数组
  image_width     INTEGER,
  image_height    INTEGER,
  size_bytes      INTEGER NOT NULL,
  source_app      TEXT,
  pinned          INTEGER NOT NULL DEFAULT 0,
  created_at      INTEGER NOT NULL,  -- 毫秒时间戳
  last_copied_at  INTEGER NOT NULL,
  copy_count      INTEGER NOT NULL DEFAULT 1
);
CREATE INDEX idx_clip_items_order ON clip_items (pinned DESC, last_copied_at DESC);

CREATE TABLE clip_settings (
  key   TEXT PRIMARY KEY,
  value TEXT NOT NULL              -- JSON
);
```

数据库带 `user_version`，启动时按版本顺序迁移。

### 6.3 写入与去重

1. 读取内容，按类型计算哈希（文本按 UTF-8 字节；图片按解码后的 RGBA 数据加宽高；文件按保持原顺序的路径列表）。
2. 哈希已存在：更新 `last_copied_at`、`copy_count`，保持置顶状态不变。
3. 不存在：图片先写入临时文件再重命名为正式文件，然后在事务中插入记录。
4. 插入后执行清理。

### 6.4 清理

- 删除超过保留天数、以及超出最大条数的非置顶条目，按 `last_copied_at` 从旧到新。
- 数据库事务提交后再删除对应图片文件。
- 启动时扫描图片目录，删除数据库中没有引用的孤立文件。
- 修改上限设置时，如果会删除已有条目，先提示将删除的数量，用户确认后执行。

### 6.5 搜索

第一版用 `LIKE` 匹配文本内容和文件路径，对 `%`、`_` 转义；500 条规模下无需全文索引。中文分词不依赖 FTS。

## 7. 隐私与安全

- **暂停监听：** 一键暂停，状态持久化；暂停期间不读取剪贴板内容。
- **敏感标记：** 按第 3 节各平台标记跳过，跳过时不读取实际内容，只累加“已跳过”计数。
- **排除应用：** 来源应用在排除列表中时跳过。Wayland 无法获取来源，界面说明此设置在该环境无效。
- **自身写入：** Pixo 写回剪贴板时记录内容哈希，下一次变化与之相同则只更新时间，不当作新记录。
- **权限最小化：** 不开启 asset 协议访问数据目录；图片通过命令以二进制响应返回，前端转为 Blob URL 并在卸载时释放。capability 只授予需要的窗口和插件权限。
- **存储安全：** 第一版不加密，依赖操作系统用户目录权限；设置页说明存储位置，并提供“清空全部历史”。是否加密列为待定问题。
- **日志：** 日志中不输出剪贴板内容，只记录类型、大小和错误码。

## 8. 命令与事件

### 8.1 命令

| 命令 | 参数 | 返回 |
|---|---|---|
| `clipboard_list` | `query?`、`kind?`、`pinnedOnly?`、`cursor?`、`limit`（1–100） | 条目摘要列表与下一页游标 |
| `clipboard_get` | `id` | 完整条目（文本全文、文件列表） |
| `clipboard_image` | `id`、`thumbnail` | PNG 二进制 |
| `clipboard_copy` | `id` | 无；写回系统剪贴板 |
| `clipboard_set_pinned` | `id`、`pinned` | 无 |
| `clipboard_delete` | `ids`（1–500） | 删除数量 |
| `clipboard_clear` | `keepPinned` | 删除数量 |
| `clipboard_read_now` | 无 | 新条目或已存在的条目；用于不支持监听的环境 |
| `clipboard_status` | 无 | 监听状态、平台能力、跳过计数 |
| `clipboard_set_paused` | `paused` | 无 |
| `clipboard_get_settings` / `clipboard_update_settings` | 设置对象 | 设置对象；校验取值范围 |

列表只返回预览，避免大文本经过 IPC。

### 8.2 事件

- `clipboard://changed`：`{ id, reason: "added" | "updated" | "removed" }`，前端据此局部刷新。
- `clipboard://status`：监听状态变化。

### 8.3 错误

Rust 返回 `{ code, params }`，前端翻译为 `zdx.text.clipboard.error.<code>`：

| code | 含义 |
|---|---|
| `unsupported` | 当前平台或环境不支持监听 |
| `permission_denied` | 系统拒绝访问剪贴板 |
| `busy` | 剪贴板被其他程序占用，重试后仍失败 |
| `not_found` | 条目不存在 |
| `too_large` | 内容超过上限 |
| `file_missing` | 文件条目中的路径已不存在（写回时提示，不阻止） |
| `storage` | 数据库或文件读写失败 |
| `invalid_input` | 参数校验失败 |
| `shortcut_conflict` | 快捷键已被占用 |

内部错误详情只写日志，不直接展示。

## 10. 实施阶段

1. **存储与文本：** 数据模型、SQLite 存储、macOS 与 Windows 文本监听、工具页列表、搜索、删除、置顶。
2. **图片与文件：** 图片存储与缩略图、文件路径、大小上限与清理。
3. **Linux：** X11 监听、Wayland 检测与 data-control 支持、不支持时的界面提示和手动读取。
4. **快速面板：** 全局快捷键、面板窗口、单实例与命令行唤出。
5. **隐私：** 敏感标记、排除应用、暂停、首次启用说明。

每个阶段独立可用，并完成对应验证后再进入下一阶段。

## 11. 待定问题

- 历史数据是否需要加密存储；如需加密，密钥是否放入系统钥匙串。
- 是否需要“自动粘贴”；如需，macOS 需要辅助功能权限，Wayland 无法实现。
- 文本上限、条数上限的默认值是否合适。
- 是否记录 HTML / RTF 原始格式。
- 新版 macOS 剪贴板隐私提示对后台监听的实际影响，需实测后确认交互方案。
