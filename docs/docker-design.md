# Docker 工具设计

> 状态：与当前实现一致　｜　适用版本：Pixo 0.1.x

## 1. 目标

用命名连接管理本机或远端的 Docker、Podman 引擎。连接方式为本机套接字和 SSH。

不包含云端账号、集群编排，以及把引擎数据同步出去。

## 2. 和 SSH 的契约

SSH 型连接引用一条已经保存在 SSH 工具里的主机。地址、端口、用户名、跳板和主机指纹都属于那条主机，不在 Docker 里再存一份。

- 指纹沿用 SSH 的规则：未知指纹要用户确认，指纹变化时阻止连接。确认写进 Pixo 自己的 known_hosts。
- 密码和口令只进系统钥匙串。Docker 的 SQLite 不保存这些秘密。仓库密码同样只进钥匙串。
- SSH 工具关闭时，SSH 型连接不能打开。界面说明原因，并给出打开 SSH 设置的入口。本机套接字连接不受这个开关影响。
- 还有 Docker 连接引用这台主机时，不能删除它。界面列出这些连接。先改掉或删除连接，再删主机。
- 这不是 SSH 工具里的端口转发界面。用户可见的本地端口转发仍由 SSH 工具负责。Docker 只为到达远端引擎套接字建立这条连接。

## 3. 离开页面

离开 Docker 页会断开当前打开的引擎连接。主机引用和连接配置留在 `docker/endpoints.db`。再次进入后需要重新连接。关闭主窗口且后台运行时，已经打开的连接保持到退出应用。

## 4. 导出

设置的数据页可以把连接导出成 JSON。文件包含名称、方式、套接字和主机引用，不包含钥匙串里的密码。
