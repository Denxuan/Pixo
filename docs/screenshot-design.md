# 截图工具设计

> 状态：草案　｜　适用版本：Pixo 0.1.x 之后的截图功能

飞书依据：[使用截图功能](https://www.feishu.cn/hc/zh-CN/articles/319286513754)、[提取图片中的文字](https://www.feishu.cn/hc/zh-CN/articles/258254899042)。本文按飞书桌面端截图的能力设计 Pixo 的截图工具。帮助文档只写了撤销；本文补上重做。

## 1. 目标与范围

在 Pixo 工具箱中新增“截图”工具。用户用快捷键或入口冻结当前画面，框选区域，完成标注后复制、保存，或把图片固定在屏幕上。

一次截图的主路径：

1. 快捷键、主窗口或托盘唤起。
2. 按显示器冻结画面，并盖上全屏遮罩。
3. 在冻结画面上框选、标注。
4. 复制到剪贴板、下载到本地，或固定到屏幕。

包含：

- 多显示器各自一块遮罩，选区、窗口吸附、尺寸标注和放大镜。
- 矩形、椭圆、箭头、画笔、高亮、马赛克、文本、标签、水印。
- 撤销和重做。
- 固定到屏幕，同一时间最多 8 张贴图。
- 滚动截图：自动向下，或跟随滚轮向上、向下，拼完后回到标注。
- 本机提取文字。可从工具栏进入，也可从托盘直接进入识字。
- 区域录屏。单独快捷键，输出 MP4，可选麦克风、系统声音和鼠标点击效果。
- 自定义快捷键、保存目录和图片格式。

不包含：

- 发送到会话、云同步、云端识字、图片翻译、会议云录制。
- 摄像头画中画、录制后剪辑和字幕。保存后的录屏进入截图库，不做单独的剪辑时间线。
- 任何未经用户当次操作的上传。翻译以后若要做，必须单独开关，并在开启时说明会上传选区图像。
- 跨多块显示器的一个选区。选区始终落在指针所在的那一块显示器内。
- Linux Wayland 上的静默冻结截图。见第 3.4 节。

复制出去的图片进入剪贴板历史。用户保存的截图和录屏进入截图库。贴图只留在内存里，退出即消失。搜索对这两处的图片都执行复制。

实现分三期，文档一次写完。第一期交付冻结画面、选区、标注、复制、下载、贴图、快捷键和设置。滚动截图和识字是第二期。录屏是第三期。未实现的能力在状态接口里标为不可用，按钮禁用并说明原因。

## 2. 设计原则

- **先冻结，再编辑。** 快捷键按下时抓取各显示器画面。之后的选区和标注都发生在这张静止图像上，桌面上的后续变化不进入画面。
- **只在本机。** 抓屏、识字、编码和保存都不经过网络。不新增网络权限。
- **系统能力在 Rust，界面在前端。** 抓屏、权限、快捷键、滚动注入、识字、编码和写文件在 Rust。选区、工具栏、标注和预览在前端。
- **不静默失败。** 权限缺失、平台不支持、编码器缺失、识字语言包缺失，都通过状态或稳定错误码告诉前端，由界面说明原因。
- **用户当次操作才写出内容。** 复制、下载、贴图、打开识别出的链接，都由对应按钮或按键触发。取消不写剪贴板，也不写文件。
- **沿用已有窗口习惯。** 遮罩、贴图和录屏条使用独立窗口标签，在 `App.tsx` 里按标签分流，和 `clipboard-panel` 一样不进入主界面路由。

## 3. 平台支持

| 能力 | macOS | Windows | Linux X11 | Linux Wayland |
|---|---|---|---|---|
| 冻结显示器画面 | 支持，需要屏幕录制权限 | 支持 | 支持 | 不支持静默抓取 |
| 窗口吸附 | 支持；权限要求实现时实测 | 支持 | 支持 | 不支持 |
| 全局快捷键 | 支持 | 支持 | 支持 | 不支持，提供命令行 |
| 滚动截图 | 支持，需要辅助功能权限 | 支持 | 支持 | 不支持 |
| 本机识字 | Vision | 系统 OCR，依赖语言包 | 已安装 tesseract 时支持 | 与 X11 相同，且依赖能拿到图像 |
| 区域录屏 | ScreenCaptureKit | Windows.Graphics.Capture | 本机编码器可用时支持 | 不支持飞书式体验 |
| 系统声音 | 系统提供本机音频采集时支持 | WASAPI 回环 | PulseAudio / PipeWire 监视源 | 不支持 |
| 麦克风 | 支持，需要麦克风权限 | 支持 | 支持 | 依赖门户或本机音频权限 |

抓屏优先使用 `xcap` 读取各显示器的物理像素。某平台的 `xcap` 结果缺行、色偏或坐标系不符时，在该平台的 `capture` 模块里替换实现，并在状态里保持同一套错误码。

### 3.1 macOS

- 截图和录屏使用屏幕录制权限。把 `screenRecording` 加入 `src-tauri/src/permissions.rs` 的状态列表，用 `CGPreflightScreenCaptureAccess` 检测，用 `CGRequestScreenCaptureAccess` 发起系统提示，并用系统设置 URL 打开“屏幕录制”。用户拒绝后界面给出手动授权说明。
- 滚动截图向其他进程注入滚轮，使用辅助功能权限。窗口吸附用 `CGWindowList` 读取边界，不为此单独弹出辅助功能授权。列表里没有其他进程的窗口时，吸附状态为不可用，自由框选照常可用。
- 识字使用 Vision 的 `VNRecognizeTextRequest`，语言包含简体中文和英文。识别在本机完成。
- 遮罩窗口层级使用 `NSScreenSaverWindowLevel`。`src-tauri/src/shortcut.rs` 里的剪贴板面板使用 `NSFloatingWindowLevel`，并注明该层级低于截图界面和菜单栏。遮罩必须高于这一层，才能盖住菜单栏、剪贴板面板和其他窗口。集合行为包含 `CanJoinAllSpaces` 和 `FullScreenAuxiliary`，使遮罩出现在当前空间，并避免把空间拉走。
- 录屏使用 ScreenCaptureKit 采集选区，再用 `AVAssetWriter` 写入 MP4。系统声音只在当前系统版本提供本机音频采集时打开开关；不可用时开关禁用并说明原因。麦克风使用麦克风权限，仅在用户打开开关后申请。
- 第一期必须在当前 macOS 上实测：权限提示是否只出现一次、拒绝后的状态，以及多块不同缩放比例的显示器上，窗口逻辑坐标和图像物理像素是否对齐。

### 3.2 Windows

- 显示器采集和区域录制可用。区域录制使用 Windows.Graphics.Capture 和 Media Foundation。
- 识字使用 `Windows.Media.Ocr`。系统没有对应语言包时，能力状态为不可用，界面说明需要安装语言包。
- 系统声音使用 WASAPI 回环。麦克风默认关闭。
- 窗口矩形用可见顶层窗口枚举。排除 Pixo 自己的窗口。

### 3.3 Linux X11

- 冻结画面、窗口吸附和滚动截图可用。窗口列表来自 `_NET_CLIENT_LIST` 与窗口几何。滚动用 XTest 或向目标窗口发送滚轮事件；实现时选定一种，并在另一种失败时返回 `capture_failed`，不交替重试到用户无感知。
- 识字仅在 `PATH` 上存在 `tesseract` 时可用。优先使用 `chi_sim+eng`；缺语言数据时返回 `ocr_unavailable`。
- 录屏依赖本机已安装的 ffmpeg 或 GStreamer。两者都不存在时返回 `encoder_missing`，界面说明需要安装哪一个。不把编码器打进应用包。

### 3.4 Linux Wayland

- Wayland 不能在没有门户授权的情况下静默抓取屏幕。xdg-desktop-portal 的选屏对话框会打断“按下快捷键即冻结”的流程，也拿不到与遮罩对齐的整屏像素。
- 启动时检测会话类型。Wayland 上截图、滚动截图和录屏的状态为“不支持”，原因写明是无法静默冻结画面。不退回 XWayland 假装可用。
- 全局快捷键插件在 Wayland 下不可用。提供 `pixo --screenshot` 和 `pixo --screenshot-record`。`src-tauri/src/lib.rs` 的单实例回调按 `--clipboard-panel` 的方式转发给已运行实例。用户在桌面环境的快捷键设置里绑定这两条命令。
- 本版不做门户选屏。门户对话框替换不了按下快捷键后的即时冻结。
- 识字引擎本身可以在 Wayland 上运行，但没有冻结画面就没有输入图像，因此识字入口同样不可用。

## 4. 用户界面

### 4.1 唤起

- 截图快捷键：macOS 默认 `Cmd+Option+A`，Windows 和 Linux 默认 `Ctrl+Alt+A`。不用飞书的 `Cmd/Ctrl+Shift+A`，避免两个程序抢同一个全局快捷键。
- 录屏快捷键：macOS 默认 `Shift+Cmd+R`，Windows 和 Linux 默认 `Alt+Shift+R`。
- 主窗口侧栏提供“截图”页，页内可以开始截图、开始识字、开始录屏，并进入设置。
- 托盘增加“截图”“提取文字”“录屏”。文案由前端把翻译后的标签传给托盘，和现有剪贴板托盘标签同一条路径。
- 设置“截图时隐藏 Pixo”默认开启。开启时，抓屏前隐藏主窗口、剪贴板面板和已有贴图，避免把 Pixo 自己截进去。
- 从主窗口或托盘进入时按住 `Shift`，无论上述设置是否开启，都先隐藏 Pixo。
- 记住进入前各窗口的可见状态。取消或结束后恢复。新创建的贴图留下。
- 已有一次编辑中的截图时，再次按下截图快捷键会取消当前编辑并重新冻结。正在录屏时，截图快捷键不开始新会话。

### 4.2 选区遮罩

每个显示器一个无边框、置顶、不进任务栏的透明窗口。页面铺满该显示器的冻结图像，选区外用半透明暗色盖住。

- 未按下鼠标时，悬停高亮指针下最上层的窗口矩形。单击该高亮即把它设为选区。
- 拖拽建立自由选区。拖拽过程中不吸附窗口。
- 选区内部拖动可移动；八个控制点可调整大小。选区限制在本显示器的物理像素范围内，宽和高至少为 1。
- 另一块显示器上按下鼠标时，清除原选区，在新显示器上开始。
- 选区外侧显示 `宽 × 高`，单位是物理像素。
- 指针旁显示放大镜，取冻结图像的局部像素，并显示该点颜色的十六进制值。
- `Esc` 取消整个会话。没有文字正在编辑时，`Enter` 把当前选区复合成 PNG，写入剪贴板并结束。
- 还没有选区时，工具栏不出现。`Enter` 不产生图片。

### 4.3 标注工具栏

工具栏贴在选区外侧。默认在选区下方；下方放不下则改到上方；上下都放不下则贴在选区内部底边。水平方向限制在该显示器工作区内。

工具：

| 工具 | 行为 |
|---|---|
| 矩形、椭圆、箭头、画笔 | 三种粗细，颜色为红、黄、绿、蓝、黑、白 |
| 高亮 | 半透明笔触，粗细和颜色同上 |
| 马赛克 | 画笔或框选，三种笔触大小。预览和确认使用同一套像素块算法，直接改冻结图像上的像素 |
| 文本 | 三种字号和上述颜色。编辑中 `Enter` 换行 |
| 标签 | 定位点加说明文字。可调字号和定位点颜色。点击定位点在左右方向间翻转 |
| 水印 | 文字、透明度和颜色，按斜向重复铺在选区上 |
| 撤销 / 重做 | 撤销上一步。重做恢复刚撤销的一步 |
| 滚动截图 | 第二期。从当前选区开始拼接 |
| 提取文字 | 第二期。对再框出的区域做本机识别 |
| 固定到屏幕 | 结束编辑并留下贴图 |
| 下载 | 按保存设置写文件并结束 |
| 保存到剪贴板 | 写入系统剪贴板并结束 |

键盘：`Ctrl/Cmd+Z` 撤销，`Ctrl/Cmd+Shift+Z` 重做。`Tab` 进入工具栏，方向键在工具间移动，`Enter` 或空格激活当前工具。正在编辑文本时，`Esc` 先结束这段文本；再按一次 `Esc` 才取消整次截图。绘制图形使用指针。

### 4.4 贴图

固定到屏幕后关闭遮罩，在原选区的屏幕位置显示一个无边框置顶窗口。

- 拖动标题区域可移动。悬停时显示“关闭”和“复制”。
- 贴图不写磁盘，退出应用即消失。图像字节只留在该贴图的内存状态里。
- 悬停或键盘聚焦时，图片顶部盖住一条 28 逻辑像素的栏，栏内可以拖动、复制和关闭。指针离开且窗口失焦后栏消失。栏不改变窗口尺寸。
- 同时最多 8 张，对应预声明的窗口标签。第 9 张返回 `pin_limit`，界面提示先关闭一张。
- 复制把这张 PNG 写入剪贴板，规则与第 6.4 节相同。

帮助文档要求贴图可拖拽位置。贴图不提供缩放，窗口逻辑尺寸等于导出图像的物理像素除以该显示器的 `scaleFactor`。双击不关闭贴图。贴图窗口获得焦点时，`Esc` 或“关闭”关掉这一张，不影响其他贴图。

### 4.5 滚动截图

从第二期开始。用户先有一个选区，再点击“滚动截图”。选区表示要保留的视口。

- 自动模式向下滚动，直到连续若干帧内容不再变化、达到高度上限，或用户按 `Esc`。
- 滚轮模式不自动滚动。用户向上或向下滚动鼠标时，采集新的一条并拼接。`Esc` 结束拼接。
- 开始前把选区中心所在的窗口置于前台，以便滚轮送到该窗口。结束后不强制把焦点切回原应用。
- 遮罩在采集每一帧前暂时让开选区，抓到这一条后再盖回，避免把遮罩拍进长图。
- 拼接使用相邻帧的重叠行：新帧相对已有图像只追加新出现的行。对不齐时停止并保留已拼上的部分，返回 `scroll_incomplete`，界面说明长图可能不完整。
- 高度上限默认 30000 物理像素。
- 拼完后遮罩恢复，冻结图像替换为这张长图。长图高于显示器时，遮罩内按物理像素纵向滚动查看，工具栏保持在屏幕内。之后的标注坐标相对于这张长图。

### 4.6 提取文字

从第二期开始。两个入口：

- 截图工具栏的“提取文字”：在当前冻结图像上再框一块区域。
- 托盘或工具页的“提取文字”：直接进入识字遮罩，框选后识别，不显示标注工具。

识别完成后显示文本面板。文本可编辑。用户可以复制选中的一段，或复制全部。关闭面板后可以重新框选。识别结果不落盘。

用本地规则找出 `http://`、`https://` 链接。只有用户点击链接时，才通过现有 opener 插件打开。不自动打开，也不发网络请求去做校验。

飞书在 Linux 上不提供这项能力。Pixo 在 Linux 上仅当 tesseract 可用时提供；不可用时按钮禁用并说明。

### 4.7 录屏

从第三期开始。录屏和截图共用选区遮罩，工具栏换成录屏选项。

- 格式只有 MP4。
- 麦克风、系统声音、鼠标点击效果三个开关。麦克风和系统声音默认关闭。鼠标点击效果默认关闭。
- 确认后倒计时 3 秒。倒计时期间 `Esc` 取消，不产生文件。
- 倒计时结束后面罩关掉，只留控制条：时长、暂停、停止、麦克风状态。控制条尽量放在选区外面；选区几乎占满显示器时，控制条盖住选区一角，这一角会被录进去，界面在开始前说明。
- 暂停期间不往文件里写新帧，成片时长不包含暂停时间。
- 停止后把 MP4 写入保存目录。录制中按 `Esc` 等同于停止；已有内容则保存，尚无帧则不产生文件。
- 不含摄像头、剪辑和字幕。

### 4.8 设置

设置放在现有系统设置页，新增“截图”分区，路径 `/settings/screenshot`。

| 设置 | 默认值 | 说明 |
|---|---|---|
| 截图快捷键 | macOS `Cmd+Option+A`，其他 `Ctrl+Alt+A` | 与录屏快捷键、剪贴板快捷键冲突时拒绝保存 |
| 录屏快捷键 | macOS `Shift+Cmd+R`，其他 `Alt+Shift+R` | 第一期只保存，第三期才注册到系统 |
| 保存目录 | 用户图片目录下的 `Pixo` | 目录不存在时尝试创建 |
| 保存格式 | PNG | PNG 或 JPEG。剪贴板和贴图始终用 PNG |
| JPEG 质量 | 90 | 取值 60–100，只对下载生效 |
| 截图时隐藏 Pixo | 开启 | `Shift` 从界面进入时强制隐藏 |
| 滚动截图最大高度 | 30000 | 物理像素，范围 2000–60000 |

文件名形如 `Pixo_20261114_153045.png`。同一秒内重名时追加 `-2`、`-3`。时间取用户本机本地时间。

完成截图时，保存到剪贴板和下载是两个按钮。下载才写文件。

### 4.9 无障碍与国际化

- 工具栏按钮提供 `aria-label`。文本输入框有可见标签或 `aria-label`。
- 取消、确认、撤销、重做和工具切换可用键盘完成。绘制和框选使用指针。
- 系统开启减少动态效果时，倒计时只切换数字，放大镜不做过渡动画。
- 文案走 i18n，前缀固定：
  - `zdx.label.screenshot.*`：工具名、按钮、设置项。
  - `zdx.text.screenshot.*`：说明、状态、错误。
  - `zdx.placeholder.screenshot.*`：水印和文本占位。
- 中英文同步维护。水印内容、识别出的文字和文件名不翻译。
- 错误展示翻译后的 `zdx.text.screenshot.error.<code>`，不展示 Rust 的 Debug 字符串。

## 5. 架构

```
快捷键 / 托盘 / 主窗口
   │
   ▼
ScreenshotSession（Rust）
   ├─ 隐藏 Pixo 窗口 → 按显示器冻结画面 → 打开遮罩
   ├─ 滚动注入、本机识字、区域编码（第二期、第三期）
   └─ 复制：系统剪贴板 + 剪贴板历史
   ▲
   │ 命令与事件 screenshot://session、screenshot://record
前端遮罩 / 贴图 / 录屏条
```

同一时间只有一个截图或录屏会话。

### 5.3 窗口与 capability

Tauri 的 capability 在构建时写死窗口标签。遮罩和贴图使用预声明标签：

- `screenshot-overlay-1` … `screenshot-overlay-8`
- `screenshot-pin-1` … `screenshot-pin-8`
- `screenshot-recorder`

超过 8 块显示器时只为前 8 块创建遮罩，状态里说明其余显示器未覆盖。单独的 `src-tauri/capabilities/screenshot.json` 列出这些标签，以及遮罩需要的窗口权限：显示、隐藏、设置位置和大小、置顶、焦点。不把这些窗口放进 `default.json` 里扩大主窗口权限。

| `xcap` | 读取各显示器物理像素 | 第一期 |

### 5.5 与剪贴板的衔接

复制和贴图上的“复制”由 `ClipboardService` 新增的 `record_produced_image` 完成。截图模块不访问 `arm` 和 `record` 这些私有步骤。该方法内部：

1. 用现有的 `hash_image` 计算哈希。
2. 调用 `arm`，把这次写入标成 Pixo 自己产生的。
3. 用现有的 `write_image` 写入系统剪贴板。失败则解除标记并返回剪贴板错误码，不写历史。
4. 写入成功后按手动记录写入历史，使剪贴板处于暂停时也能留下这一条。监听线程随后看到同一次变化时，命中已有标记，只更新原记录，不再插入第二条。

历史仍遵守剪贴板的图片类型开关。类型关闭或历史未启用时，系统剪贴板写入成功，历史跳过，结果为 `skipped_disabled`。

剪贴板监听的单张上限仍是解码后 20 MB（`max_image_bytes`）。截图这条路径单独使用 80 MB。80 MB 对应 20,971,520 个像素：5120×2880 可以写入历史，8192×2880 会超过上限。超过时系统剪贴板仍写入，历史跳过，结果为 `skipped_too_large`。界面说明“已复制，未写入历史”。不放宽监听其他图片时的 20 MB 上限。

下载不写剪贴板。保存到剪贴板不写文件。

## 6. 数据与坐标

### 6.1 设置与临时文件

- 设置：`<app_data_dir>/screenshot/settings.json`。写入先到临时文件，再替换，避免写到一半损坏。
- 冻结画面：`<app_cache_dir>/screenshot/session/<id>/<index>.bin`，内容为第 16.6 节的原始像素。会话结束、取消、应用启动时删除整个 `session` 目录。PNG 只在复制、下载和贴图时生成。
- 下载文件：用户设置的保存目录。
- 贴图和识字文本不写文件。

全屏图像不放进 base64 JSON。遮罩通过命令按显示器取回字节。不为此开启 asset 协议，和剪贴板图片的约束一致。

快捷键按下到遮罩可见，在普通 1080p 或 1440p 显示器上的目标是低于约 300 ms。缓存直接写原始像素，避免为了上屏先做整屏 PNG 编码。实现时分别记录抓屏、写文件和创建窗口的耗时。没测过的分辨率不写成已经达到。

### 6.2 坐标

Rust 为每块显示器提供：

- 屏幕坐标中的原点、物理像素宽高、缩放比例。
- 工作区，用于把工具栏限制在任务栏或菜单栏之外。图像本身仍覆盖整块显示器，包含菜单栏区域。

窗口的位置和大小使用 Tauri 的逻辑坐标。选区、标注和导出图像使用物理像素。前端用 Rust 给出的 `scaleFactor` 把指针位置换算成图像坐标，不单独信任 `devicePixelRatio`。两块缩放比例不同的显示器必须各算各的。实现阶段在这种组合上核对一次点选位置和导出裁切。

### 6.3 马赛克

三种笔触对应 8、16、24 物理像素的块边长。块内取平均色再填回。画笔路径覆盖到的块和框选矩形覆盖到的块都参与计算。预览调用同一函数，确认时的导出也调用它。

### 6.4 复制与下载的字节

- 剪贴板和贴图：PNG。
- 下载：设置中的 PNG 或 JPEG。JPEG 把图像画到不透明背景上再编码，质量取设置值。

## 7. 隐私与安全

- 抓屏结果只在会话缓存和用户指定的保存目录出现。日志只记显示器数量、选区宽高、耗时和错误码，不记像素，不记识字正文，不记水印文字。
- 麦克风和系统声音默认关闭。打开麦克风才申请麦克风权限。
- 识别出的链接只在用户点击后打开。
- 取消会话时删除本次缓存。启动时清掉上次崩溃留下的 `session` 目录。
- capability 只包含截图窗口需要的权限。不增加网络权限，不放宽主窗口的文件访问。
- 滚动截图会把目标窗口切到前台并注入输入。开始前提示这一行为；用户点击滚动后才注入。

### 8.2 事件

- `screenshot://session`：`{ phase: "live" | "cancelled" | "finished" }`。遮罩和主窗口用来收起界面。
- `screenshot://scroll`：拼接进度，包含已获得的高度和是否停止。
- `screenshot://record`：`{ phase: "countdown" | "recording" | "paused" | "finished" | "cancelled", elapsedMs }`。

### 8.3 错误

Rust 返回 `{ code, params }`，前端翻译为 `zdx.text.screenshot.error.<code>`。

| code | 含义 |
|---|---|
| `unsupported` | 当前平台没有这项能力 |
| `permission_denied` | 屏幕录制、辅助功能或麦克风被拒绝 |
| `capture_failed` | 抓屏或滚动注入失败 |
| `scroll_incomplete` | 长图已停止，重叠对不齐或达到上限 |
| `ocr_unavailable` | 没有识字引擎或语言包 |
| `encoder_missing` | 没有可用的录屏编码器 |
| `too_large` | 超出滚动高度或历史特例上限 |
| `pin_limit` | 贴图已有 8 张 |
| `busy` | 正在录屏，不能开始截图 |
| `storage` | 设置或文件写入失败 |
| `invalid_input` | 参数或设置超出范围 |
| `shortcut_conflict` | 快捷键与截图、录屏或剪贴板冲突 |
| `cancelled` | 用户取消；通常不作为错误弹窗 |

内部原因只写日志。

## 11. 会话与指针

遮罩是多个 WebView，标注不能只放在其中一个页面的内存里。已提交的文档放在 Rust 会话中。拖拽过程中的预览只画在指针所在的遮罩上，指针抬起时提交一次。撤销栈跟着文档放在会话里，最多 50 步，每步是提交前的整份快照。换到另一块显示器并开始新选区时，其余遮罩立刻去掉旧选区的边框和工具栏；新选区在抬起时写入会话，撤销可以回到换屏之前的文档。

会话阶段：

```
preparing → live → finishing → closed
               ├─ scrolling → live
               └─ recognizing → live

录屏：live → countdown → recording ⇄ paused → finishing → closed
```

`preparing` 期间若屏幕录制权限不足，不隐藏任何窗口，直接返回 `permission_denied`。权限足够时才记住主窗口、剪贴板面板和贴图的可见性并隐藏，然后抓屏。抓屏失败则恢复这些窗口，发出带错误码的 `screenshot://session`，不留下遮罩。

同一进程只有一个会话。`preparing` 或 `live` 时再次开始截图，会取消当前会话并重新冻结。`recording`、`paused` 和录屏倒计时期间再次截图返回 `busy`。

指针：

- 按下和抬起之间的位移小于 4 个物理像素时，按点击处理。
- 点击吸附高亮的窗口：把它设为选区，清空标注。这一步在抬起时提交，占一步撤销。
- 在选区外拖拽：用新矩形替换选区，并清空标注。拖拽过程中只显示预览；抬起时提交一步。拖拽中按 `Esc` 放弃这次手势，恢复按下时的文档，不结束会话。
- 调整大小使用八个控制点。控制点的可点范围至少为 8 个逻辑像素。当前工具是“调整”时，在选区内部拖动是移动整个选区。标注留在图像坐标上，缩小选区不删除选区外的标注，导出时再裁掉。
- 绘制工具处于选中状态时，选区内部的拖拽用来绘制。再点一次当前绘制工具，回到“调整”。
- 点在工具栏、属性条或文本面板上的指针不改变选区。
- 没有选区时不处理 `Enter`。指针按下期间、文本或水印输入框聚焦时，`Enter` 不触发复制。其余情况下 `Enter` 复制并结束。
- 双击不作为完成或关闭。遮罩吃掉指针事件，右键不弹出系统菜单，也不取消会话。
- 键盘焦点给指针所在的遮罩。`Esc`、`Enter`、撤销和重做作用在会话里的那一份文档上。

放大镜在 `live` 且没有输入框聚焦、指针不在工具栏上时显示。它是 128 逻辑像素的正方形，用最近邻放大指针周围 32×32 物理像素，并标出中心点颜色 `#RRGGBB`。尺寸标签用 `宽 × 高`，放在选区右下角外侧 8 像素；超出工作区时改到选区右上角外侧。

复制成功且历史已写入或因类型关闭而跳过时，遮罩立即关闭。历史因 80 MB 上限跳过时，遮罩保留一句说明，约 1.2 秒后关闭。保存或复制失败时遮罩留下，工具栏显示错误，用户可以重试或取消。

长图高于当前显示器时，滚轮滚动视口，每档 80 物理像素。绘制工具选中时滚轮仍然滚动视口，不开始新笔画。笔画坐标换算到长图坐标。

## 12. 标注文档

坐标相对于当前冻结图像或长图的物理像素，原点在图像左上角。选区是这份文档的裁切范围。

```
color = red | yellow | green | blue | black | white
size  = sm | md | lg

mark =
  rect | ellipse      { x, y, w, h, size, color }
  arrow               { x1, y1, x2, y2, size, color }
  pen | highlight     { points, size, color }
  mosaic-pen          { points, size }
  mosaic-rect         { x, y, w, h, size }
  text                { x, y, w, text, size, color }
  tag                 { anchorX, anchorY, text, size, color, side: left | right }

document = { selection, marks, watermark }
watermark = { text, opacity, color } | none
```

六色的值固定为 `#E5484D`、`#F5C518`、`#30A46C`、`#3B82F6`、`#1C1C1C`、`#FFFFFF`。线宽 sm/md/lg 为 2/4/8 物理像素。文本字号为 14/22/32。马赛克块边长为 8/16/24，与第 6.3 节是同一组数。高亮用对应颜色的 45% 不透明度。箭头头部长度为线宽的 4 倍。

新建选区后的当前工具是“调整”。各工具记住本次会话内最后一次使用的颜色和粗细。初始为红色、中等线宽、中等字号、中等马赛克。水印默认白色、不透明度 40%。

属性条出现在主工具栏旁边，只显示当前工具用得到的项：图形和高亮显示线宽与颜色，马赛克显示画笔或框选以及块大小，文本显示字号和颜色，标签再加定位点颜色和翻转，水印打开输入、不透明度和颜色。水印文字为空时不绘制水印。

提交规则：

- 矩形、椭圆、框选马赛克的宽或高小于 2，或箭头长度小于 2 时，抬起后丢弃，不产生撤销步。
- 画笔、高亮和马赛克画笔少于 2 个点时丢弃。
- 绘制点限制在选区矩形内。
- 文本或标签失焦时内容为空，则删除该项；若它从未有过内容，不产生撤销步。
- 单条文本最多 4000 个字符，水印最多 40 个字符，单条笔画最多 8000 个点，标注总数最多 300。超出时 `screenshot_editor_commit` 返回 `invalid_input`，前端保留预览并提示。

合成顺序仍是冻结图像、马赛克、图形和高亮、文本和标签、水印。导出时按选区裁切，选区外的笔画像素不进入结果。

## 13. 滚动拼接

拼接是纯函数，放在 `scroll.rs`，用夹具测试，不依赖真实显示器。自动滚动的循环调用它。

每一跳滚动选区高度的 75%，使相邻帧大约保留 25% 重叠。自动模式每 200 ms 一跳。滚轮模式由遮罩把一档滚轮变成一次 `screenshot_scroll_feed`；上一次喂帧尚未返回时，忽略新的滚轮。

对齐时取已有图像末端 25% 行，在新帧里滑动，计算每个偏移的通道平均绝对误差。误差低于 8（通道范围 0–255）的偏移里，取误差最小的一个。只把新出现的行接到指定方向。连续两帧的最佳重叠等于整段重叠且误差低于 8 时，视为到底，正常结束。没有合格偏移时停止，结果带 `scroll_incomplete`。自动模式还有 80 跳的上限，先达到高度上限或跳数上限就停止。

前端显示已经拼上的物理像素高度。`Esc` 以当时的结果结束并回到标注。

## 14. 录屏参数与状态

默认参数写死在第三期实现里，不先做设置项：每秒 30 帧，H.264，视频码率 8 Mbps，关键帧间隔 2 秒。打开了麦克风或系统声音时增加一条 AAC，128 kbps。两个声音开关都关闭时，文件不包含音轨。最长 30 分钟，到时自动停止并保存，控制条说明已到达时长上限。

鼠标点击效果画进视频帧：半径 18 物理像素、线宽 2、颜色 `#3B82F6` 的圆环，在点击后 300 ms 内淡出。不依赖一块可能被采集排除在外的系统图层。

倒计时显示在遮罩上。开始写第一帧之前先隐藏全部遮罩，并等到窗口报告已隐藏。500 ms 内没有隐藏确认就取消，返回 `capture_failed`，不留文件。这样第一帧不会拍进遮罩。

用户打开麦克风但权限被拒绝时，仍然开始无麦克风的录制，事件里带 `micDenied: true`，控制条说明麦克风未录上。系统声音不可用时开关保持禁用，不会在开始之后才失败。

暂停只停止写入新帧，不关闭文件。停止时若一帧都没有，删除未完成文件并返回空路径。

## 15. 工具页与权限时序

工具页 `Screenshot.tsx` 展示三样东西：当前能力状态、三个动作（开始截图、提取文字、录屏）、进入设置的入口。不展示历史图片。不可用的动作禁用，并在按钮旁显示 `screenshot_status` 给出的原因。

屏幕录制权限不在应用启动时索取。用户第一次开始截图或录屏时，macOS 才调用一次系统请求。拒绝后返回 `permission_denied`，工具页提供打开系统设置的按钮。若系统要重新打开应用后权限才生效，状态原因为 `relaunch_required`。界面说明需要重新打开 Pixo，不自动退出或重启。

现有权限提示继续只在用户真正用到对应能力时出现。缺少屏幕录制权限不阻止剪贴板功能。

识字和录屏在第一期、第二期尚未实现时，状态为不可用，工具页同样禁用按钮。不摆一个会失败的主路径。

## 16. 画面与数据契约

### 16.1 遮罩上的两层

冻结图像画在 canvas 上。canvas 的像素宽高等于该显示器的物理像素，CSS 尺寸等于物理像素除以 `scaleFactor`。这样预览的一个设备和导出的一个像素是同一点。工具栏、放大镜和尺寸标签是 HTML，用逻辑像素定位，不画进这张 canvas。

导出使用另一张只包含选区物理像素的 canvas：先从冻结图像裁出选区，再按第 12 节的顺序画标注。不把 CSS 缩放后的画面再截一次。

选区外覆盖 `rgba(0, 0, 0, 0.45)`。选区边框为 2 物理像素 `#3B82F6`。八个控制点为 8 逻辑像素的白底方块，描边 `#3B82F6`。吸附高亮使用同样的 2 像素蓝色边框，没有控制点。

放大镜和尺寸标签的规则见第 11 节。放大镜放在指针右下方 16 逻辑像素；该位置超出工作区时改到左上方。

### 16.2 工具栏

工具栏高 40 逻辑像素，内边距 4，按钮 32×32，间距 4，圆角 8。底色 `#1C1C1C`、不透明度 92%，图标 18 像素、白色。当前工具的按钮底色为 `#3B82F6`。

从左到右：矩形、椭圆、箭头、画笔、高亮、马赛克、文本、标签、水印、撤销、重做、滚动截图、提取文字、固定到屏幕、下载、保存到剪贴板、取消。第一期里滚动截图和提取文字按状态禁用。

属性条高 36，与主栏间距 6，外观相同。主栏在选区下方时，属性条放在主栏上方；主栏翻到选区上方时，属性条放在主栏下方。

### 16.3 文本、标签和水印

预览和导出使用同一字体串：`ui-sans-serif, system-ui, sans-serif`。字号按物理像素解释。行高为字号的 1.4 倍。

文本框的换行宽度默认 240 物理像素，并且不超过选区右边界留下的空间；剩余不足 80 时仍用 80，允许画出选区，导出再裁切。第一期不给文本框加缩放手柄。

标签的定位点是半径 6 物理像素的实心圆。气泡内边距 8，圆角 6，最大宽度 240，文字在气泡内换行。`side = right` 时，气泡左边距定位点 12；`side = left` 时，气泡右边距定位点 12。气泡在定位点的垂直方向居中。翻转只改变 `side`。

水印绕选区中心旋转 -24 度，只画在选区内。相邻文字的水平空档和垂直空档都是 48 物理像素。不透明度取文档里的值，默认 0.4，允许范围 0.1–1。

画笔、高亮和箭头的端点使用圆头。高亮多次叠在同一位置时按 45% 不透明度逐次叠加。箭头尖端在终点，箭身停在箭头底边中点，底边张角 26 度，箭长为线宽的 4 倍。

### 16.4 马赛克对齐

块网格从图像原点 `(0, 0)` 起算，不从笔触的包围盒起算。一个块只要有任意像素落在马赛克形状里，就用这个块内全部像素的平均色填满整块。块超出图像的部分丢掉。相邻笔画落在同一块时只平均一次。预览和导出调用这个函数。

### 16.5 窗口过滤

吸附候选必须可见、和该显示器相交、面积至少 64×64 物理像素，并且不属于 Pixo 进程。按 Z 序从顶往下找第一个包含指针的窗口。若它的四边都距显示器边缘不超过 8 像素，就跳过它继续找下一个，避免桌面或全屏根窗口挡住所有悬停。没有更小窗口时，才把这块显示器本身当作选区。

### 16.6 冻结字节

`screenshot_frame` 返回的文件布局：

| 偏移 | 内容 |
|---|---|
| 0 | 4 字节 `PXFR` |
| 4 | `u32` 小端宽度 |
| 8 | `u32` 小端高度 |
| 12 | `u32` 小端每行字节数，等于宽度 × 4 |
| 16 | 从上到下、从左到右的 RGBA，每像素 4 字节 |

宽度、高度或行字节数与文件长度不一致时，遮罩显示 `capture_failed`，并允许用户取消。不尝试按 PNG 再解析一遍。

### 16.7 文档版本

会话版本从 0 开始。`screenshot_editor_commit` 只在 `baseVersion` 等于当前版本时写入，成功后版本加 1。撤销和重做同样加 1，并把新版本交回前端。版本不符时返回 `invalid_input`，文档不变；前端重新 `screenshot_editor_get`，丢弃本地预览。这样两块遮罩不会互相覆盖。

`finishing` 和 `closed` 阶段不再接受提交。

### 16.8 显示器变化

`live` 期间显示器数量或某块显示器的原点、物理尺寸、缩放比例发生变化时，取消会话，恢复进入前的窗口，错误参数为 `display_changed`。不把旧图像挪到新的坐标系上。

### 16.9 识字面板

识别中的面板只显示进行中的状态，不放空文本冒充结果。完成后面板包含可编辑文本、“复制全部”和“关闭”。链接不插进可编辑文本里，另列在面板下方。正则是 `https?://` 后连续的非空白字符，并去掉结尾的 `.,;:!?)]`。识别完成后链接列表不再随编辑改变。关闭面板回到框选，不提交标注文档。

### 16.10 已经定下的选择

- 上屏缓存使用原始像素。不因为大屏实测再改成 PNG。
- 窗口列表为空时关闭吸附，不追加辅助功能弹窗。
- 本版不做 Wayland 门户选屏。
- 贴图不缩放。
- 历史特例上限保持 80 MB。
- 录屏参数保持第 14 节，不提前做设置项。
