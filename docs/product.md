# Pixo 产品定义

Pixo 是留在本机的桌面工具箱。主手势是搜索：在任意应用里打开它，找到一条记录、一台主机或一个连接，或直接开始截图、录屏、暂停剪贴板。

四个工具默认关闭。第一次打开时勾选要留下的，只为这些工具申请权限。之后可以在设置里单独开关。已经保存过开关的安装保持原样；截图不再对全新安装默认开启。

## 准入

再加一个工具时，它要同时满足：

- 数据留在本机，不因为方便而上传。
- 可以整项关闭，关闭后入口、快捷键和托盘项一起退出。
- 权限说得清，并且只在这个工具打开时申请。
- 和现有工具共享一种对象或一个手势。对象是剪贴板记录、图片、主机、连接。手势是搜索、托盘、全局快捷键。

不把云同步、账号和插件加载放进这个产品。

## 唤起

用户动作登记在 `src/commands/registry.ts`。搜索在没有输入时列出已开启工具的动作；输入「设置」或 “privacy” 时列出设置和数据页。同一类图片只有一个主动作：复制回剪贴板。主机和 Docker 连接的主动作是打开并连接。录屏文件打开截图页。

快捷键仍在各工具设置里修改。冲突时注册失败，并提示用户改掉其中一个。Wayland 上全局快捷键不可用时，仍用 `pixo --clipboard-panel` 和 `pixo --screenshot`。

## 数据

| 对象 | 位置 | 保留 | 清空 |
|---|---|---|---|
| 剪贴板记录 | 应用数据目录 `clipboard/history.db`，图片在同目录 `images` | 未置顶的按条数和天数；置顶一直留着 | 设置的数据页可清空未置顶记录 |
| 截图库 | `screenshot/library.db` | 直到用户删除 | 在截图页删除 |
| 保存的截图和录屏 | 用户选择的图片目录，默认图片文件夹下的 Pixo | 文件留在该目录 | 由用户在系统文件管理器里处理 |
| 贴图 | 内存 | 退出应用即消失 | 关闭贴图 |
| SSH 主机 | `ssh/hosts.db` | 直到删除 | 在主机列表删除 |
| 密码和口令 | 系统钥匙串，服务名 `pixo.ssh` | 直到用户取消记住或系统清除 | 不写入导出文件 |
| Docker 连接 | `docker/endpoints.db` | 直到删除 | 在连接列表删除 |
| 仓库密码 | 系统钥匙串 | 同上 | 不写入导出文件 |

这一版不给这些文件再加一层应用加密。它们以明文存在当前用户的应用数据目录，依赖操作系统的账户隔离。

导出主机或连接时，只写名称、地址、方式和证书或私钥的路径。

## 离开之后

| | 关闭窗口且后台运行 | 从菜单栏退出 | 再次打开 |
|---|---|---|---|
| 剪贴板记录 | 继续 | 还在磁盘上 | 还在 |
| 快捷键和托盘 | 继续 | 停止 | 按开关恢复 |
| SSH | 已连接的会话继续 | 断开 | 恢复上次的标签，不自动连接 |
| Docker | 已打开的连接继续 | 断开 | 需要再连接 |
| 录屏 | 继续 | 停止 | 不续录 |
| 贴图 | 还在 | 消失 | 不恢复 |

托盘提示在剪贴板状态之外，会加上正在录屏、SSH 会话数和 Docker 连接数。
